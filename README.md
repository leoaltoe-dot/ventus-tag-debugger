# ventus-tag-debugger
Ventus Tag Debugger é uma extensão para Google Chrome criada para facilitar a validação, auditoria e debugging de implementações de tracking diretamente durante a navegação.

A ferramenta monitora eventos e requisições em tempo real, permitindo visualizar a trajetória das tags, Data Layer relacionado, parâmetros enviados, origem das requisições, containers GTM, informações de atribuição como source / medium e possíveis problemas de implementação.

Entre os principais recursos estão:

Monitoramento de tags em tempo real
Inspeção de Data Layer por evento
Captura de requests diretamente do Network
Identificação de GA4, Google Tag Manager, Meta Pixel, Google Ads e outras plataformas
Identificação de GTM Web e Server-Side
Status HTTP e diagnóstico de erros
Histórico organizado por domínio
Limpeza automática do histórico após 24 horas
Controle para ligar/desligar a captura
Cópia rápida de erros e status das tags
Análise individual de tags utilizando IA
Identificação de parâmetros ausentes e possíveis problemas de mensuração
Interface focada em profissionais de Digital Analytics, Tracking, Analytics Engineering e Data Science

Tecnologias: JavaScript, HTML, CSS, Chrome Extension Manifest V3, Cloudflare Workers e OpenAI API.
